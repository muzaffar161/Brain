# Цифровой нейрон (v0) — Hodgkin–Huxley на C++

Экспериментальный симулятор: биофизическая модель клетки с ионными каналами «под капотом», синапсом между двумя нейронами и архитектурой под рост сети.

## Что даёт этот эксперимент

Не только картинка спайка, а измеримые величины:

| Сигнал | Смысл |
|--------|--------|
| `V(t)` | мембранный потенциал |
| `m, h, n` | ворота Na/K — почему возникает спайк |
| `I_Na`, `I_K`, `I_L` | токи каналов |
| `I_syn`, `g_syn` | синаптический ток A→B |

**Критерий успеха v0:** нейрон A при постоянном токе даёт регулярные спайки; на графиках видно открытие/закрытие ворот; спайки A вызывают EPSP / спайки в B.

## Сборка и запуск

```bash
cmake -S . -B build
cmake --build build
./build/brain_hh data/trace.csv

python3 -m venv .venv
.venv/bin/pip install matplotlib
.venv/bin/python scripts/plot.py data/trace.csv -o data/trace.png
```

## Архитектура

```
Network  →  Neuron (сома + Na/K/Leak)
         →  Synapse (conductance-based)
Simulator → CSV → scripts/plot.py
```

Добавить 10-й нейрон — это данные сети (`add_neuron` / `add_synapse`), а не новый алгоритм.

Уравнение сомы:

```
C_m dV/dt = I_ext + I_syn - I_Na - I_K - I_L
```

Синапс: при спайке пресинаптической клетки `g += weight`, далее `dg/dt = -g/τ`, ток `I = g (V_post - E_syn)`.

## Параметры эксперимента (main)

- Нейрон A: `I_ext = 10 µA/cm²`
- Нейрон B: `I_ext = 0`
- Синапс A→B: `weight = 1.5`, `E_syn = 0 mV`, `τ = 2 ms`
- `dt = 0.01 ms`, длительность `100 ms`
